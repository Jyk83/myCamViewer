    ├── 📄 ARCHITECTURE.md          # 아키텍처 상세 설계

=====================================

주요 파일 설명
=====================================

🎯 시작 파일 (읽기 권장 순서)
  1. QUICKSTART.md              - 5분 안에 시작하기
  2. README.md                  - 프로젝트 전체 개요
  3. PROJECT_SUMMARY.md         - 설계 및 평가 요약

🔨 빌드 스크립트
  build_all.bat                 - 전체 자동 빌드 (권장)
  build_native.bat              - C++ DLL만 빌드
  build_csharp.bat              - C# 앱만 빌드

💻 C++ 레이어 (NativeRenderer/)
  renderer.h                    - API 인터페이스 정의
  renderer.cpp                  - OpenGL 렌더링 구현
  CMakeLists.txt                - CMake 빌드 설정

🖥️ C# 레이어 (WinFormsApp/)
  CamViewerControl.cs           - ⭐ 핵심 컨트롤 (WinCC에 이걸 삽입)
  MainForm.cs                   - 테스트용 폼
  Program.cs                    - 애플리케이션 진입점

📚 상세 문서 (Docs/)
  ARCHITECTURE.md               - 설계 원칙 및 데이터 흐름
  BUILD_GUIDE.md                - 빌드 문제 해결 포함
  WINCC_INTEGRATION.md          - WinCC 통합 단계별 가이드

=====================================

빌드 출력물
=====================================

빌드 성공 시 다음 파일이 생성됩니다:

NativeRenderer/build/bin/Release/
  └── NativeRenderer.dll        - C++ 렌더링 엔진 DLL

WinFormsApp/bin/Release/
  ├── CamViewerPOC.exe          - 메인 실행 파일
  ├── CamViewerPOC.exe.config   - 설정 파일
  └── NativeRenderer.dll        - 종속 DLL (자동 복사)

WinCC 배포용 파일
=====================================

WinCC Advanced에 배포 시 필요한 파일:

필수 파일:
  ✅ CamViewerControl.cs        (또는 컴파일된 DLL)
  ✅ NativeRenderer.dll         (반드시 포함!)

선택 파일:
  📄 README.md                  (사용자 가이드)
  📄 WINCC_INTEGRATION.md       (통합 가이드)

배포 위치:
  TIA_Project/Runtime/
    ├── CamViewerControl.Library.dll
    └── NativeRenderer.dll

=====================================

중요 참고 사항
=====================================

⚠️ NativeRenderer.dll 위치
   - 반드시 CamViewerPOC.exe와 같은 폴더에 있어야 함
   - WinCC 배포 시에도 마찬가지

⚠️ 플랫폼 설정
   - C++ DLL: x64 (64-bit)
   - C# 앱: Any CPU (권장) 또는 x64

⚠️ .NET Framework 버전
   - 4.7.2 이상 필요
   - WinCC Advanced v17 요구사항과 일치

⚠️ Visual Studio 요구사항
   - 2019 또는 2022
   - C++ 및 .NET 워크로드 설치 필요
