   ✓ DLL 존재 여부

🐛 가장 흔한 원인 3가지
═══════════════════════════════════════════════════════════════

원인 1: DLL이 없음
────────────────────────────────────────────────────────────
증상: "NativeRenderer.dll not found"

해결:
  copy NativeRenderer\build\bin\Release\NativeRenderer.dll ^
       WinFormsApp\bin\Release\


원인 2: 아키텍처 불일치 ⚠️ 가장 가능성 높음!
────────────────────────────────────────────────────────────
증상: "Platform mismatch error" 또는 BadImageFormatException

원인:
  • DLL은 x64 (64-bit)
  • 프로그램이 x86 (32-bit)로 실행됨

해결:
  1. Visual Studio 열기
  2. 상단 플랫폼 드롭다운에서 "x64" 선택
  3. 다시 빌드

  또는

  1. 프로젝트 우클릭 → Properties
  2. Build 탭
  3. Platform target: x64 선택
  4. 저장 후 빌드


원인 3: OpenGL 미지원
────────────────────────────────────────────────────────────
증상: "Failed to initialize OpenGL renderer"

해결:
  • 그래픽 드라이버 업데이트
  • 가상머신이면 3D 가속 활성화
  • 원격 데스크톱이면 물리적 PC에서 테스트

📋 단계별 진단
═══════════════════════════════════════════════════════════════

Step 1: DLL 확인
  cmd:
    cd WinFormsApp\bin\Release
    dir NativeRenderer.dll

  있어야 함: ✓ NativeRenderer.dll


Step 2: 플랫폼 확인
  Visual Studio에서:
    상단 플랫폼 드롭다운 확인
    
  "Any CPU" 또는 "x86" → "x64"로 변경!


Step 3: 다시 빌드
  Build → Clean Solution
  Build → Rebuild Solution


Step 4: DLL 다시 복사 (필요시)
  copy NativeRenderer\build\bin\Release\NativeRenderer.dll ^
       WinFormsApp\bin\Release\

  또는 x64 플랫폼인 경우:
  copy NativeRenderer\build\bin\Release\NativeRenderer.dll ^
       WinFormsApp\bin\x64\Release\


Step 5: 실행 및 테스트
  WinFormsApp\bin\Release\CamViewerPOC.exe
  
  또는
  
  WinFormsApp\bin\x64\Release\CamViewerPOC.exe
