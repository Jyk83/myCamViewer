🎯 가장 쉬운 방법 (1분 소요)
═══════════════════════════════════════════════════════════════

1단계: CamViewerPOC.sln 파일을 더블클릭
   → Visual Studio가 자동으로 열립니다

2단계: 상단에서 "Debug"를 "Release"로 변경

3단계: 빌드
   → 메뉴: Build → Build Solution
   → 또는 단축키: Ctrl + Shift + B

4단계: 실행
   → WinFormsApp\bin\Release\CamViewerPOC.exe 더블클릭

성공! 🎉

═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════

1. 시작 메뉴에서 검색: "Developer Command Prompt for VS"

2. 프로젝트 폴더로 이동:
   cd "D:\4. HKHMI\Project\WinCC\Genspark\CamViewerPOC"

3. 빌드 스크립트 실행:
   build_csharp_simple.bat

4. 실행:
   WinFormsApp\bin\Release\CamViewerPOC.exe

🔧 빌드 후 확인 사항
═══════════════════════════════════════════════════════════════

필수 파일이 있는지 확인:

✅ WinFormsApp\bin\Release\CamViewerPOC.exe
✅ WinFormsApp\bin\Release\NativeRenderer.dll

두 파일이 모두 있어야 정상 실행됩니다!

═══════════════════════════════════════════════════════════════

🎮 실행 후 테스트
═══════════════════════════════════════════════════════════════

프로그램이 실행되면:

1. "Sample Shapes" 버튼 클릭
   → 미리 정의된 도형이 나타남

2. "Add Rectangle" 버튼 클릭
   → 랜덤 사각형 추가

3. "Add Circle" 버튼 클릭
   → 랜덤 원형 추가

4. 마우스 휠
   → 확대/축소 (줌)

5. 오른쪽 버튼 드래그
   → 화면 이동 (패닝)

6. "Clear Scene" 버튼
   → 모든 도형 제거

7. "Reset View" 버튼
   → 뷰 초기화

═══════════════════════════════════════════════════════════════

❓ 문제가 발생하면?
═══════════════════════════════════════════════════════════════

1. "MSBuild를 찾을 수 없습니다"
   → Visual Studio가 설치되어 있는지 확인
   → CamViewerPOC.sln을 Visual Studio로 여세요

2. "DLL을 찾을 수 없습니다"
   → NativeRenderer.dll을 수동 복사:
   copy "NativeRenderer\build\bin\Release\NativeRenderer.dll" ^
        "WinFormsApp\bin\Release\"

3. 자세한 문제 해결:
   → BUILD_TROUBLESHOOTING.md 파일을 참조하세요
