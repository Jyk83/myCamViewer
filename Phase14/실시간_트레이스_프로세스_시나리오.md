# 실시간 트레이스 프로세스 시나리오 (Real-time Trace Process Scenario)

## 📋 개요 (Overview)
본 문서는 HK 레이저 절단 CAM 뷰어의 실시간 트레이스 프로세스를 설명합니다.
**샘플 MPF 파일**: `1.MPF` (2개 파트, 파트1: 8개 컨투어, 파트2: 5개 컨투어)

---

## 🔄 전체 프로세스 흐름도

```
[MPF 파일 로드] 
    ↓
[MPF 파싱 및 데이터 구조화]
    ↓
[OpenGL 렌더링 초기화]
    ↓
[ITag 서버 연결]
    ↓
[ReadTagCyclic 시작] ← WinCC HMI에서 iTag 주기적 읽기
    ↓
[절단 시작 대기]
    ↓
[실시간 절단 진행 추적] ← NC 컨트롤러 데이터 수신
    ↓
[렌더링 업데이트 및 진행 상태 표시]
    ↓
[절단 완료]
    ↓
[리소스 정리]
```

### 1.2 MPF 파일 파싱
**관련 클래스**: `MPFParser.cs`

```csharp
private void LoadMpfFile(string filePath)
{
    try
    {
        // 1. MPF 파일 읽기
        string content = File.ReadAllText(filePath);
        
        // 2. MPFParser로 파싱
        var parser = new MPFParser();
        mpfProgram = parser.Parse(content);  // MPFProgram 객체 생성
        
        // 3. CamViewerCore에 프로그램 데이터 전달
        camViewerControl.LoadProgram(mpfProgram);
        
        // 4. ITag Write: MPF 파일 경로 전달
        tagManager.WriteTag("HMI_MPF_PATH", filePath);
        
        LogHelper.Log("RealtimeITagControl", $"MPF 로드 성공: {filePath}");
    }
    catch (Exception ex)
    {
        MessageBox.Show($"MPF 로드 오류: {ex.Message}");
    }
}
```

## 🖼️ 2단계: OpenGL 렌더링 초기화

### 2.1 CamViewerCore 초기화
**관련 클래스**: `CamViewerCore.cs`, `NativeRenderer.cs` (C++ OpenGL)

```csharp
public void LoadProgram(MPFProgram program)
{
    this.mpfProgram = program;
    
    // 1. 네이티브 렌더러 초기화
    if (!isInitialized)
    {
        InitializeRenderer();
    }
    
    // 2. 텍스트 렌더러 초기화
    if (!textRendererInitialized)
    {
        InitializeTextRenderer();
    }
    
    // 3. 형상 데이터를 OpenGL 버퍼로 전송
    BuildGeometry();
    
    // 4. 화면 다시 그리기
    Invalidate();
}

private void BuildGeometry()
{
    foreach (var part in mpfProgram.Parts)
    {
        foreach (var contour in part.Contours)
        {
            foreach (var segment in contour.AllSegments)
            {
                if (segment is LineSegment line)
                {
                    // C++ OpenGL에 라인 데이터 전송
                    NativeRenderer.AddLine(line.Start.X, line.Start.Y, 
                                          line.End.X, line.End.Y);
                }
                else if (segment is ArcSegment arc)
                {
                    // C++ OpenGL에 아크 데이터 전송
                    NativeRenderer.AddArc(arc.Start.X, arc.Start.Y,
                                         arc.End.X, arc.End.Y,
                                         arc.Center.X, arc.Center.Y,
                                         arc.IsClockwise);
                }
            }
        }
    }
}
```

### 2.2 렌더링 요소
- **기본 형상**: 모든 컨투어의 라인/아크 세그먼트
- **파트/컨투어 번호**: RenderSettings.ShowPartNumbers, ShowContourNumbers
- **선택 하이라이트**: 선택된 컨투어는 빨간색으로 강조
- **절단 진행 표시**: 현재 절단 중인 엘리먼트는 녹색으로 표시

private void OnTagDataChanged(object sender, TagDataEventArgs e)
{
    try
    {
        // 1. 태그 데이터 추출
        int partNumber = e.GetInt("HMI_NC_PART_NUMBER");
        int contourNumber = e.GetInt("HMI_NC_CONTOUR_NUMBER");
        int elementIndex = e.GetInt("HMI_NC_ELEMENT_INDEX");
        double progress = e.GetDouble("HMI_NC_PROGRESS");

    }
    catch (Exception ex)
    {
        LogHelper.Log("RealtimeITagControl", $"태그 데이터 처리 오류: {ex.Message}");
    }
}

### 4.2 CuttingProgressManager 상태 업데이트
**관련 클래스**: `CuttingProgressManager.cs`

```csharp
public bool StartCuttingProgress(int partNumber, int contourNumber, bool reverse = false)
{
    // 1. 인덱스 변환 (1-based → 0-based)
    int partIdx = partNumber - 1;      // 0
    int contourIdx = contourNumber - 1; // 4
    
    // 2. 유효성 검사
    if (partIdx < 0 || partIdx >= program.Parts.Count) return false;
    if (contourIdx < 0 || contourIdx >= program.Parts[partIdx].Contours.Count) return false;
    
    // 3. 상태 초기화
    currentPartIndex = partIdx;         // 0
    currentContourIndex = contourIdx;   // 4
    currentElementIndex = 0;
    elementProgress = 0.0;
    isUnderCuttingProgress = true;
    hasCuttingProgress = false;
    
    // 4. 이벤트 발생
    OnProgressUpdated(new CuttingProgressEventArgs
    {
        PartIndex = 0,           // 0-based
        ContourIndex = 4,        // 0-based
        ElementIndex = 0,
        Progress = 0.0,
        State = CuttingState.InProgress
    });
    
    return true;
}
```

### 4.3 렌더링 업데이트
**관련 클래스**: `CamViewerCore.cs`

```csharp
private void CuttingProgressManager_ProgressUpdated(object sender, CuttingProgressEventArgs e)
{
    // 1. 현재 절단 위치 저장
    currentCuttingPartIndex = e.PartIndex;
    currentCuttingContourIndex = e.ContourIndex;
    currentCuttingElementIndex = e.ElementIndex;
    currentCuttingProgress = e.Progress;
    
    // 2. OpenGL 렌더링 업데이트 (하이라이트)
    if (e.PartIndex >= 0 && e.ContourIndex >= 0)
    {
        var part = mpfProgram.Parts[e.PartIndex];
        var contour = part.Contours[e.ContourIndex];
        
        // 현재 절단 중인 컨투어를 녹색으로 하이라이트
        HighlightContour(e.PartIndex, e.ContourIndex, Color.Green);
        
        // 현재 절단 중인 엘리먼트를 밝은 녹색으로 강조
        if (e.ElementIndex < contour.AllSegments.Count)
        {
            HighlightElement(e.PartIndex, e.ContourIndex, e.ElementIndex, 
                           Color.LimeGreen, e.Progress);
        }
    }
    
    // 3. 화면 다시 그리기
    Invalidate();
    
    // 4. 로그 기록
    LogHelper.Log("CamViewerCore", 
        $"절단 진행: P{e.PartIndex+1} C{e.ContourIndex+1} E{e.ElementIndex} ({e.Progress:P1})");
}
```

private void ProgressManager_ProgressUpdated(object sender, CuttingProgressEventArgs e)
{
    // UI 업데이트 (Invoke 필요 - 다른 스레드에서 호출)
    if (InvokeRequired)
    {
        Invoke(new Action(() => ProgressManager_ProgressUpdated(sender, e)));
        return;
    }
    
    // 1. 위치 정보 표시
    numPart.Value = e.PartIndex + 1;
    numContour.Value = e.ContourIndex + 1;
    numElement.Value = e.ElementIndex;
    trackProgress.Value = (int)(e.Progress * 100);
    lblProgressValue.Text = $"{e.Progress:P1}";
    
    // 2. 상태 표시
    lblStatus.Text = e.State switch
    {
        CuttingState.Idle => "대기 중",
        CuttingState.InProgress => "절단 진행 중",
        CuttingState.Paused => "일시 정지",
        CuttingState.Completed => "절단 완료",
        _ => "알 수 없음"
    };
    
    // 3. 로그 추가
    AddLog($"업데이트: P{e.PartIndex+1} C{e.ContourIndex+1} E{e.ElementIndex} ({e.Progress:P1})");
    
    if (e.ContourChanged)
    {
        AddLog($"→ 컨투어 변경: C{e.ContourIndex+1}");
    }
}

    LogHelper.Log("RealtimeITagControl", "전체 절단 완료");
    
    // 3. UI 버튼 상태 변경
    btnStart.Enabled = true;
    btnStop.Enabled = false;
    
    // 4. 렌더링 최종 업데이트
    camViewerControl.SetCuttingCompleted();
    
    // 5. 통계 정보 표시
    MessageBox.Show($"절단 완료!\n총 절단 거리: {totalCutDistance:F2} mm\n소요 시간: {elapsedTime}");
