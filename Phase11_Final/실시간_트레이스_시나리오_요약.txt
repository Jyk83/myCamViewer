[핵심 클래스]
1. MPFParser: MPF 파일 파싱
   - Parse(content) → MPFProgram

2. MPFProgram: 프로그램 데이터 구조
   - Parts[] → Contours[] → AllSegments[]

3. CuttingProgressManager: 절단 진행 상태 관리
   - StartCuttingProgress(partNumber, contourNumber, reverse)
   - UpdateProgress(partNumber, contourNumber, elementIndex, progress)
   - StopCuttingProgress()
   - ResetCuttingProgress()

4. ITagManager: ITag 통신 (Singleton)
   - Connect() / Disconnect()
   - StartReadTagCyclic(tagNames[])
   - StopReadTagCyclic()
   - WriteTag(tagName, value)

5. CamViewerCore: OpenGL 렌더링
   - LoadProgram(program)
   - BuildGeometry()
   - HighlightContour(partIdx, contourIdx, color)
   - HighlightElement(partIdx, contourIdx, elemIdx, color, progress)

6. RealtimeITagControl: 전체 컨트롤러
   - LoadMpfFile(filePath)
   - OnTagDataChanged(sender, e)

7. TraceTestForm: 수동 테스트 UI
   - BtnStart_Click() → StartCuttingProgress()
   - BtnUpdate_Click() → UpdateProgress()
   - BtnCompleteElement_Click() → elementIndex++
   - BtnCompleteContour_Click() → contourIndex++

[ITag 태그 목록]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[ReadTagCyclic - NC → HMI]
- HMI_NC_PART_NUMBER      : 현재 절단 중인 파트 번호 (1-based)
- HMI_NC_CONTOUR_NUMBER   : 현재 절단 중인 컨투어 번호 (1-based)
- HMI_NC_ELEMENT_INDEX    : 현재 절단 중인 엘리먼트 인덱스 (0-based)
- HMI_NC_PROGRESS         : 엘리먼트 진행률 (0.0 ~ 1.0)
- HMI_NC_WCS_X            : WCS X 좌표
- HMI_NC_WCS_Y            : WCS Y 좌표
- HMI_NC_GCODE_BLOCK      : 현재 G-Code 블록 문자열
- HMI_NC_MPF_LINE_NO      : MPF 라인 번호

[WriteTag - HMI → NC]
- HMI_MPF_PATH            : MPF 파일 경로
- HMI_VIEW_SEARCH_PART    : 선택된 파트 번호 (컨투어 클릭 시)
- HMI_VIEW_SEARCH_CONT    : 선택된 컨투어 번호 (컨투어 클릭 시)
