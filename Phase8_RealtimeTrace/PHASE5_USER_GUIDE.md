## 빠른 시작 (Quick Start)

### 1단계: MPF 파일 로드

1. **"Load MPF" 버튼** 클릭
2. MPF 파일 선택 (예: `test_mpf.mpf`, `ColdAir.mpf`)
3. 캔버스에 파트들이 자동으로 표시됩니다

### 2단계: 기본 탐색

- **줌 인/아웃**: 마우스 휠 스크롤
- **패닝(화면 이동)**: 왼쪽/오른쪽/중간 마우스 버튼 드래그
- **뷰 리셋**: "Reset View" 버튼 클릭

### 3단계: Phase 5 기능 사용

**선택 모드 활성화**:
- **컨투어 선택**: "컨투어 (Contour)" 라디오 버튼 선택
- **엘리먼트 선택**: "엘리먼트 (Element)" 라디오 버튼 선택
- **선택 해제**: "없음 (None)" 라디오 버튼 선택

**파트 외곽선 표시**:
- **Render Settings** → **"파트 외곽선 표시 (Show Part Boundaries)"** 체크

**번호 위치 조정**:
- **"파트 번호 위치 (Part #)"** 버튼 클릭 → 파트 클릭 → 원하는 위치 클릭
- **"컨투어 번호 위치 (Contour #)"** 버튼 클릭 → 컨투어 클릭 → 원하는 위치 클릭

**캔버스 회전**:
- **Render Settings** → **"캔버스 방향 (Canvas Orientation)"** 드롭다운에서 각도 선택

## 기능별 사용법 (Feature Guides)

### 5.1 & 5.2: 선택 기능 (Selection)

#### 컨투어 선택 (Contour Selection)

**목적**: 전체 컨투어(윤곽선)를 선택하여 하이라이트 표시

**사용법**:

1. **선택 모드 활성화**:
   - 왼쪽 패널에서 **"컨투어 (Contour)"** 라디오 버튼 선택

2. **컨투어 선택**:
   - 캔버스에서 원하는 컨투어의 아무 위치나 클릭
   - 선택된 컨투어는 **노란색(Yellow)**으로 하이라이트되며 **두꺼운 선**으로 표시됩니다

3. **다른 컨투어 선택**:
   - 다른 컨투어를 클릭하면 이전 선택이 해제되고 새로운 컨투어가 선택됩니다

4. **선택 해제**:
   - **"없음 (None)"** 라디오 버튼 선택
   - 또는 빈 공간 클릭 (컨투어가 없는 영역)

**시각적 피드백**:
- **선택된 컨투어**: 노란색, 원래 선 두께의 2.5배
- **미선택 컨투어**: 원래 색상 및 두께 유지

**활용 예시**:
- 특정 컨투어의 가공 순서 확인
- 컨투어 레벨의 시뮬레이션 실행
- 컨투어 정보 검사

---

#### 엘리먼트 선택 (Element Selection)

**목적**: 컨투어 내 개별 경로 세그먼트(직선, 호)를 선택

**사용법**:

1. **선택 모드 활성화**:
   - 왼쪽 패널에서 **"엘리먼트 (Element)"** 라디오 버튼 선택

2. **단일 엘리먼트 선택**:
   - 경로 세그먼트(직선 또는 호)를 클릭
   - 선택된 엘리먼트는 **마젠타(Magenta)**로 하이라이트되며 **1.5배 두께**로 표시됩니다

3. **다중 엘리먼트 선택**:
   - **"다중 선택 (Multi-select)"** 체크박스 활성화
   - **Ctrl + 클릭**으로 여러 엘리먼트를 추가 선택
   - 다시 Ctrl + 클릭하면 해당 엘리먼트 선택 해제

4. **전체 선택 해제**:
   - **"없음 (None)"** 라디오 버튼 선택
   - 또는 "다중 선택" 체크박스 해제 후 빈 공간 클릭

**클릭 허용 오차**:
- 기본값: **10 픽셀**
- 엘리먼트 중심에서 10픽셀 이내를 클릭하면 선택됩니다
- 줌 레벨에 따라 자동으로 조정됩니다

**시각적 피드백**:
- **선택된 엘리먼트**: 마젠타, 원래 선 두께의 1.5배
- **미선택 엘리먼트**: 원래 색상 및 두께 유지

**활용 예시**:
- 특정 경로의 좌표 확인
- 문제 있는 세그먼트 식별
- 엘리먼트 레벨 시뮬레이션 실행

---

#### 시뮬레이션 중 선택 사용

**중요**: 선택과 시뮬레이션은 독립적으로 작동합니다.

**동작 방식**:
- **시뮬레이션 실행 중**에도 선택/선택 해제 가능
- 선택된 항목은 시뮬레이션 색상 변화와 함께 하이라이트 유지
- 시뮬레이션이 선택된 엘리먼트에 도달하면 하이라이트가 일시적으로 덮어쓰기됩니다

**활용 예시**:
```
1. 특정 컨투어 선택 (노란색으로 하이라이트)
2. 시뮬레이션 시작
3. 시뮬레이션이 선택된 컨투어를 가공하는 모습 관찰
4. 시뮬레이션 종료 후 하이라이트 다시 표시
```

### 5.3: 파트 외곽선 (Part Boundaries)

**목적**: 각 파트의 경계를 점선 사각형으로 표시

**사용법**:

1. **외곽선 표시 활성화**:
   - **Render Settings** 버튼 클릭
   - **"파트 외곽선 표시 (Show Part Boundaries)"** 체크박스 활성화

2. **외곽선 스타일 설정**:

   **색상 변경**:
   - 색상 버튼 클릭 → 색상 선택 대화상자에서 원하는 색상 선택
   - 기본값: 연한 파란색 (Light Blue)

   **선 두께 조정**:
   - 두께 스피너에서 값 입력 (0.5 ~ 10.0)
   - 기본값: 1.5

   **점선 패턴 선택**:
   - 드롭다운에서 패턴 선택:
     - **Solid (실선)**: 연속된 실선
     - **Dash1 (긴 점선)**: `---- ---- ----` (긴 대시)
     - **Dash2 (중간 점선)**: `--- --- ---` (중간 대시)
     - **Dash3 (짧은 점선)**: `-- -- --` (짧은 대시)
     - **DotDash (점-선)**: `-.-.-.-` (점과 대시 교대)
     - **DotDotDash (점-점-선)**: `..-..-..-` (두 점과 대시 교대)
   - 기본값: Dash2 (중간 점선)

3. **설정 적용**:
   - **"OK"** 버튼 클릭
   - 변경사항이 즉시 캔버스에 반영됩니다

**경계 계산 방식**:
- 파트 내 모든 컨투어의 **최소/최대 좌표**를 기반으로 Bounding Box 계산
- 호(Arc)는 16개 세그먼트로 근사하여 정확한 경계 계산

**시각적 효과**:
- 외곽선은 모든 파트 주위에 사각형으로 표시
- 파트 번호가 표시되면 자동으로 외곽선도 표시
- 줌/패닝에 따라 크기 자동 조정

**활용 예시**:
- 파트 간 간격 확인
- 작업 영역 범위 파악
- 배치 레이아웃 검토

### 5.4: 번호 위치 설정 (Number Positioning)

**목적**: 파트 번호와 컨투어 번호의 표시 위치를 사용자가 직접 지정

#### 파트 번호 위치 설정 (Part Number Positioning)

**사용법**:

1. **위치 설정 모드 활성화**:
   - **"파트 번호 위치 (Part #)"** 버튼 클릭
   - 마우스 커서가 **십자선(Crosshair)**으로 변경됩니다

2. **파트 선택**:
   - 번호를 이동할 파트의 **아무 위치나 클릭**
   - 파트의 Bounding Box 내부를 클릭하면 선택됩니다

3. **위치 지정**:
   - 원하는 위치를 **두 번째 클릭**
   - 파트 번호가 클릭한 위치로 이동합니다
   - 위치 설정 모드가 자동으로 종료됩니다

4. **다른 파트 번호 이동**:
   - 1~3단계 반복

**취소 방법**:
- **Esc 키** 또는 **오른쪽 마우스 버튼** 클릭

---

#### 컨투어 번호 위치 설정 (Contour Number Positioning)

**사용법**:

1. **위치 설정 모드 활성화**:
   - **"컨투어 번호 위치 (Contour #)"** 버튼 클릭
   - 마우스 커서가 **십자선(Crosshair)**으로 변경됩니다

2. **컨투어 선택**:
   - 번호를 이동할 컨투어의 **경로 위를 클릭**
   - Point-in-Polygon 알고리즘으로 컨투어가 자동 감지됩니다

3. **위치 지정**:
   - 원하는 위치를 **두 번째 클릭**
   - 컨투어 번호가 클릭한 위치로 이동합니다
   - 위치 설정 모드가 자동으로 종료됩니다

4. **다른 컨투어 번호 이동**:
   - 1~3단계 반복

**취소 방법**:
- **Esc 키** 또는 **오른쪽 마우스 버튼** 클릭

---

#### 위치 저장 및 불러오기

**위치 저장 (Save Positions)**:

1. **"위치 저장 (Save Positions)"** 버튼 클릭
2. 파일 저장 대화상자에서 위치 지정 (예: `positions.json`)
3. **"저장"** 클릭
4. 성공 메시지 확인: "위치 정보가 저장되었습니다."

**위치 불러오기 (Load Positions)**:

1. **"위치 불러오기 (Load Positions)"** 버튼 클릭
2. 파일 선택 대화상자에서 JSON 파일 선택
3. **"열기"** 클릭
4. 성공 메시지 확인: "위치 정보를 불러왔습니다."
5. 캔버스가 자동으로 다시 그려집니다

**JSON 파일 형식**:
```json
{
  "customPartPositions": {
    "0": { "x": 0.5, "y": 0.3 },
    "1": { "x": -0.2, "y": 0.4 }
  },
  "customContourPositions": {
    "0_0": { "x": 0.1, "y": 0.2 },
    "1_2": { "x": -0.3, "y": -0.1 }
  }
}
```

**좌표 시스템**:
- World 좌표계 사용 (OpenGL 단위)
- 줌/패닝에 독립적으로 동작
- 회전 시에도 위치 유지

---

#### 기본 위치로 복원

**개별 번호 복원**:
- 현재는 지원되지 않음 (향후 기능)

**전체 복원**:
- 번호 위치를 저장하지 않고 프로그램 종료
- 또는 빈 JSON 파일 불러오기:
  ```json
  {
    "customPartPositions": {},
    "customContourPositions": {}
  }
  ```

**기본 위치 규칙**:
- **파트 번호**: 파트의 원점(Origin) 위치
- **컨투어 번호**: 첫 번째 피어싱 포인트(Piercing Point) 위치

---

#### 실전 팁

**1. 번호가 겹칠 때**:
- 위치 설정 모드로 각 번호를 분산 배치
- 파트 외곽선을 참고하여 빈 공간에 배치

**2. 작은 컨투어의 번호**:
- 줌 인 후 정확한 위치에 배치
- 컨투어 외부에 배치 가능

**3. 회전된 뷰에서 사용**:
- World 좌표계 사용으로 회전 후에도 상대 위치 유지
- 회전 전에 위치를 설정하면 자연스러운 배치

**4. 프로젝트별 관리**:
- MPF 파일명과 동일한 이름으로 JSON 저장 (예: `ColdAir.json`)
- 프로젝트 폴더에 저장하여 관리

### 5.5: 캔버스 회전 (Canvas Rotation)

**목적**: 캔버스를 90도 단위로 회전하여 다양한 각도에서 파트 관찰

**사용법**:

1. **Render Settings 열기**:
   - **"Render Settings"** 버튼 클릭

2. **회전 각도 선택**:
   - **"캔버스 방향 (Canvas Orientation)"** 드롭다운 클릭
   - 4가지 옵션 중 선택:
     - **0° (기본)**: 회전 없음 (원래 방향)
     - **90° CW (시계방향)**: 시계방향으로 90도 회전
     - **180°**: 180도 회전 (상하좌우 반전)
     - **270° CW (반시계방향)**: 시계방향으로 270도 회전 (반시계 90도와 동일)

3. **설정 적용**:
   - **"OK"** 버튼 클릭
   - 캔버스가 즉시 회전됩니다

**회전 축**:
- Z축 중심으로 회전 (2D 평면 회전)
- 회전 중심: 캔버스 중앙 (0, 0)

**회전 영향**:
- **회전되는 요소**:
  - 파트 및 컨투어
  - 피어싱 포인트
  - 파트 외곽선
  - 배경 이미지 (설정된 경우)
  
- **회전되지 않는 요소**:
  - 파트 번호 및 컨투어 번호 (항상 읽기 쉬운 방향)
  - UI 컨트롤 패널
  - 마우스 커서

**좌표 변환**:
- World 좌표계는 회전에 따라 변환됩니다
- 사용자 정의 번호 위치는 상대적 위치 유지

**활용 예시**:
- 기계 장착 방향에 맞춰 회전
- 작업자의 시점에 맞춰 조정
- 스크린 캡처 시 최적 각도 선택
- 레이저 헤드 방향 확인

## 키보드 및 마우스 조작 (Controls Reference)

### 마우스 조작

| 동작 | 기능 | 모드 |
|------|------|------|
| **마우스 휠 스크롤** | 줌 인/아웃 | 항상 가능 |
| **왼쪽 버튼 클릭** | - 선택 모드: 컨투어/엘리먼트 선택<br>- 위치 설정 모드: 파트/컨투어 선택 및 위치 지정<br>- 일반 모드: 패닝 시작 | 모드에 따라 다름 |

| **오른쪽 버튼 드래그** | 패닝 (화면 이동) | 항상 가능 |
| **중간 버튼 드래그** | 패닝 (화면 이동) | 항상 가능 |
| **Ctrl + 왼쪽 클릭** | 다중 엘리먼트 선택 추가/제거 | 엘리먼트 선택 모드 + 다중 선택 활성화 시 |
| **오른쪽 버튼 클릭** | 위치 설정 모드 취소 | 위치 설정 모드 중 |

## 일반적인 사용 시나리오 (Common Workflows)

### 시나리오 1: 파트 검사 및 분석

**목표**: 로드된 MPF 파일의 특정 파트를 상세히 검사

**단계**:

1. **파일 로드**:
   - "Load MPF" → MPF 파일 선택 → "열기"

2. **파트 경계 확인**:
   - "Render Settings" → "파트 외곽선 표시" 체크 → "OK"
   - 모든 파트의 경계가 점선 사각형으로 표시됨

3. **관심 파트 확대**:
   - 마우스 휠로 해당 파트 확대
   - 왼쪽 버튼 드래그로 파트를 화면 중앙에 배치

4. **컨투어 선택 및 검사**:
   - "컨투어 (Contour)" 라디오 버튼 선택
   - 검사할 컨투어 클릭 (노란색으로 하이라이트)
   - 컨투어의 경로와 형상 확인

5. **엘리먼트 수준 검사**:
   - "엘리먼트 (Element)" 라디오 버튼 선택
   - "다중 선택 (Multi-select)" 체크박스 활성화
   - Ctrl + 클릭으로 문제 있는 세그먼트들 선택 (마젠타로 하이라이트)

6. **시뮬레이션 실행**:
   - "Contour Sim" 또는 "Element Sim" 버튼 클릭
   - 가공 순서 및 경로 확인
   - 선택된 항목들이 하이라이트 상태 유지

**결과**: 특정 파트의 구조와 가공 경로를 상세히 파악

---

### 시나리오 2: 번호 위치 최적화

**목표**: 파트 및 컨투어 번호가 기하학적 요소와 겹치지 않도록 배치

**단계**:

1. **초기 뷰 확인**:
   - MPF 파일 로드
   - "Reset View"로 전체 뷰 확인
   - 번호가 겹치는 영역 식별

2. **파트 번호 재배치**:
   - "파트 번호 위치 (Part #)" 버튼 클릭
   - 겹치는 파트 클릭 (십자선 커서 상태)
   - 파트 외부의 빈 공간 클릭하여 번호 이동
   - 다른 파트 번호도 반복

3. **컨투어 번호 재배치**:
   - "컨투어 번호 위치 (Contour #)" 버튼 클릭
   - 겹치는 컨투어 클릭
   - 컨투어 외부 또는 내부의 빈 공간 클릭하여 번호 이동
   - 다른 컨투어 번호도 반복

4. **결과 확인**:
   - 모든 번호가 명확하게 보이는지 확인
   - 줌 인/아웃하여 다양한 레벨에서 가독성 확인

5. **위치 저장**:
   - "위치 저장 (Save Positions)" 버튼 클릭
   - 파일명 입력 (예: `ColdAir_positions.json`)
   - "저장" 클릭

6. **다음 세션에서 불러오기**:
   - 동일한 MPF 파일 로드
   - "위치 불러오기 (Load Positions)" 버튼 클릭
   - 저장한 JSON 파일 선택
   - 번호들이 설정한 위치로 자동 배치됨

**결과**: 깔끔하게 정리된 번호 배치로 가독성 향상

---

### 시나리오 3: 다양한 각도에서 파트 검토

**목표**: 파트를 여러 각도로 회전하여 최적의 작업 방향 결정

**단계**:

1. **기본 뷰 (0°)**:
   - MPF 파일 로드
   - 파트의 원래 방향 확인

2. **90도 회전 테스트**:
   - "Render Settings" → "캔버스 방향" → "90° CW (시계방향)" → "OK"
   - 파트가 시계방향으로 90도 회전
   - 이 각도에서의 가공 가능성 평가

3. **180도 회전 테스트**:
   - "Render Settings" → "캔버스 방향" → "180°" → "OK"
   - 파트가 상하좌우 반전
   - 기계 장착 방향 대비 확인

4. **270도 회전 테스트**:
   - "Render Settings" → "캔버스 방향" → "270° CW (반시계방향)" → "OK"
   - 파트가 반시계방향으로 90도 회전 (시계방향 270도)
   - 작업자 시점 확인

5. **최적 각도 선택**:
   - 4가지 각도 중 최적의 각도 결정
   - 해당 각도로 설정 후 "OK"

6. **스크린 캡처** (선택 사항):
   - 최적 각도에서 화면 캡처
   - 작업 지시서나 문서에 활용

**결과**: 작업 환경에 최적화된 파트 방향 결정

---

### 시나리오 4: 컨투어별 가공 순서 시뮬레이션

**목표**: 각 컨투어의 가공 순서를 시각적으로 확인하고 선택된 컨투어 추적

**단계**:

1. **파일 로드 및 설정**:
   - MPF 파일 로드
   - "파트 외곽선 표시" 활성화 (선택 사항)

2. **첫 번째 컨투어 선택**:
   - "컨투어 (Contour)" 라디오 버튼 선택
   - 첫 번째로 확인할 컨투어 클릭 (노란색 하이라이트)

3. **시뮬레이션 실행**:
   - "Contour Sim" 버튼 클릭
   - 속도 슬라이더로 시뮬레이션 속도 조정
   - "Play" 버튼으로 시작

4. **선택된 컨투어 추적**:
   - 시뮬레이션이 진행되는 동안 선택된 컨투어(노란색) 관찰
   - 해당 컨투어가 가공될 때 색상 변화 확인

5. **다른 컨투어 선택 및 반복**:
   - "Pause" 버튼으로 일시정지
   - 다른 컨투어 클릭하여 선택 변경
   - 시뮬레이션 계속 진행 또는 리셋 후 재실행

6. **엘리먼트 수준 시뮬레이션** (상세 확인):
   - "엘리먼트 (Element)" 라디오 버튼 선택
   - 특정 세그먼트 클릭 (마젠타 하이라이트)
   - "Element Sim" 버튼으로 세그먼트별 가공 관찰

**결과**: 전체 가공 프로세스의 이해와 잠재적 문제점 사전 식별

## 문제 해결 (Troubleshooting)

### 선택 기능 문제

#### 문제: 컨투어/엘리먼트가 선택되지 않음

**가능한 원인**:
1. 선택 모드가 "없음 (None)"으로 설정되어 있음
2. 클릭 위치가 정확하지 않음
3. 줌 레벨이 너무 낮아 클릭 허용 오차 범위 밖

**해결 방법**:
1. **선택 모드 확인**:
   - "컨투어 (Contour)" 또는 "엘리먼트 (Element)" 라디오 버튼이 선택되어 있는지 확인
   
2. **줌 인**:
   - 마우스 휠로 대상을 확대
   - 정확한 위치 클릭
   
3. **클릭 허용 오차 확인**:
   - 엘리먼트 선택 시 세그먼트 중심에서 10픽셀 이내 클릭 필요
   - 줌 인하면 허용 오차 범위가 World 좌표로 자동 확대

---

#### 문제: 다중 선택이 작동하지 않음

**가능한 원인**:
1. "다중 선택 (Multi-select)" 체크박스가 비활성화되어 있음
2. Ctrl 키를 누르지 않고 클릭
3. 엘리먼트 선택 모드가 아님

**해결 방법**:
1. **다중 선택 활성화**:
   - "다중 선택 (Multi-select)" 체크박스 활성화 확인
   
2. **Ctrl 키 사용**:
   - 엘리먼트 추가 선택 시 **Ctrl + 왼쪽 클릭** 사용
   
3. **선택 모드 확인**:
   - "엘리먼트 (Element)" 라디오 버튼 선택 확인
   - 컨투어 선택 모드는 다중 선택 미지원

---

### 파트 외곽선 문제

#### 문제: 파트 외곽선이 표시되지 않음

**가능한 원인**:
1. "파트 외곽선 표시" 체크박스가 비활성화되어 있음
2. 외곽선 색상이 배경색과 유사함
3. 파트에 컨투어가 없음 (데이터 문제)

**해결 방법**:
1. **설정 확인**:
   - "Render Settings" → "파트 외곽선 표시 (Show Part Boundaries)" 체크박스 활성화
   
2. **색상 변경**:
   - 외곽선 색상을 배경색과 대비되는 색으로 변경 (예: 흰색, 노란색)
   
3. **데이터 확인**:
   - MPF 파일이 올바르게 로드되었는지 확인
   - 다른 MPF 파일로 테스트

---

#### 문제: 점선 패턴이 실선으로 보임

**가능한 원인**:
1. 점선 패턴이 "Solid (실선)"으로 설정됨
2. 줌 레벨이 너무 낮아 대시 간격이 픽셀 이하
3. 선 두께가 너무 얇음

**해결 방법**:
1. **패턴 확인**:
   - "Render Settings" → "파트 외곽선 패턴" → "Dash2 (중간 점선)" 또는 다른 점선 패턴 선택
   
2. **줌 인**:
   - 대시 간격을 명확히 보기 위해 확대
   
3. **선 두께 증가**:
   - 두께를 2.0 이상으로 설정하여 가시성 향상

---

### 번호 위치 설정 문제

#### 문제: 번호 위치 설정 모드가 종료되지 않음

**가능한 원인**:
1. 위치 지정 클릭을 완료하지 않음
2. 파트/컨투어 선택 단계에서 오류 발생

**해결 방법**:
1. **수동 취소**:
   - **Esc 키** 또는 **오른쪽 마우스 버튼** 클릭
   - 마우스 커서가 기본 화살표로 변경되는지 확인
   
2. **모드 재시작**:
   - 취소 후 버튼을 다시 클릭하여 모드 재시작

---

#### 문제: 파트/컨투어를 선택할 수 없음

**가능한 원인**:
1. 클릭 위치가 Bounding Box 밖 (파트 번호 설정 시)
2. Point-in-Polygon 범위 밖 (컨투어 번호 설정 시)
3. 줌 레벨이 너무 낮음

**해결 방법**:
1. **파트 번호 설정 시**:
   - 파트 외곽선을 참고하여 경계 내부 클릭
   - "파트 외곽선 표시"를 활성화하여 범위 확인
   
2. **컨투어 번호 설정 시**:
   - 컨투어 경로 위를 직접 클릭
   - 줌 인하여 정확한 위치 클릭
   
3. **재시도**:
   - 다른 위치를 클릭해보거나 줌 레벨 조정 후 재시도

---

#### 문제: JSON 파일을 불러왔지만 위치가 적용되지 않음

**가능한 원인**:
1. JSON 파일 형식이 올바르지 않음
2. 파트/컨투어 인덱스가 현재 MPF와 일치하지 않음
3. 파일 경로에 특수문자 포함

**해결 방법**:
1. **JSON 형식 확인**:
   - 텍스트 에디터로 JSON 파일 열기
   - 형식이 다음과 같은지 확인:
     ```json
     {
       "customPartPositions": {
         "0": { "x": 0.5, "y": 0.3 }
       },
       "customContourPositions": {
         "0_0": { "x": 0.1, "y": 0.2 }
       }
     }
     ```
   
2. **인덱스 확인**:
   - 저장된 위치의 파트/컨투어 인덱스가 현재 MPF에 존재하는지 확인
   - 인덱스가 일치하지 않으면 해당 위치는 무시됨
   
3. **파일 경로**:
   - 한글이나 특수문자가 없는 경로 사용
   - 예: `C:\Projects\positions.json`

---

### 캔버스 회전 문제

#### 문제: 회전이 적용되지 않음

**가능한 원인**:
1. Render Settings에서 "OK" 버튼을 누르지 않음
2. OpenGL 변환 오류

**해결 방법**:
1. **설정 적용 확인**:
   - "Render Settings" → 회전 각도 선택 → **"OK" 버튼 클릭** 필수
   - "Cancel" 버튼은 설정 미적용
   
2. **뷰 새로고침**:
   - "Reset View" 버튼 클릭 후 다시 회전 설정
   
3. **재시작**:
   - 문제가 지속되면 프로그램 재시작

---

#### 문제: 회전 후 마우스 조작이 이상함

**참고**: 이것은 **정상 동작**입니다.

**설명**:
- 회전 후에도 마우스 이벤트는 화면 좌표계를 사용
- World 좌표계가 회전되었으므로 패닝 방향이 회전된 것처럼 느껴질 수 있음

**사용법**:
- 회전된 상태에서도 정상적으로 줌/패닝 가능
- 잠시 적응 후 자연스럽게 사용 가능

---

### 일반적인 문제

#### 문제: 성능 저하 (느린 렌더링)

**가능한 원인**:
1. 매우 복잡한 MPF 파일 (수천 개의 세그먼트)
2. 시뮬레이션과 선택이 동시에 활성화
3. 고해상도 디스플레이

**해결 방법**:
1. **시뮬레이션 일시정지**:
   - 선택 작업 시 시뮬레이션 일시정지 또는 중지
   
2. **불필요한 기능 비활성화**:
   - 사용하지 않는 파트 외곽선 표시 해제
   - 텍스트 오버레이 개수 최소화 (향후 옵션)
   
3. **데이터 최적화**:
   - MPF 파일을 간소화하거나 영역별로 분할

---

#### 문제: 프로그램이 응답하지 않음

**가능한 원인**:
1. 매우 큰 MPF 파일 로드 중
2. JSON 파일 처리 중 오류
3. 무한 루프 또는 교착 상태

**해결 방법**:
1. **잠시 대기**:
   - 큰 파일의 경우 로딩에 시간이 걸릴 수 있음
   - 10초 정도 대기 후에도 응답 없으면 다음 단계 진행
   
2. **작업 관리자에서 종료**:
   - Ctrl + Shift + Esc → "CamViewerPOC.exe" 선택 → "작업 끝내기"
   
3. **재시작 및 작은 파일로 테스트**:
   - 프로그램 재시작
   - 작은 MPF 파일로 테스트하여 문제 원인 격리

## FAQ (자주 묻는 질문)

### 일반 질문

**Q1: Phase 5 기능을 사용하려면 특별한 설정이 필요한가요?**

A: 아니요, 모든 Phase 5 기능은 기본적으로 활성화되어 있습니다. MPF 파일을 로드한 후 바로 사용할 수 있습니다.

---

**Q2: 여러 파트를 동시에 선택할 수 있나요?**

A: 현재 버전에서는 다음을 지원합니다:
- **컨투어 선택**: 단일 선택만 가능 (한 번에 하나의 컨투어)
- **엘리먼트 선택**: 다중 선택 가능 (Ctrl + 클릭으로 여러 엘리먼트)

파트 단위 선택은 향후 기능으로 예정되어 있습니다.

---

**Q3: 번호 위치 설정이 MPF 파일을 수정하나요?**

A: 아니요, 번호 위치는 별도의 JSON 파일에 저장되며 원본 MPF 파일은 절대 수정되지 않습니다. JSON 파일을 삭제하면 기본 위치로 돌아갑니다.

---

**Q4: 캔버스 회전은 MPF 데이터를 변경하나요?**

A: 아니요, 회전은 시각적 표현만 변경합니다. 실제 MPF 데이터나 좌표는 변경되지 않습니다. 회전은 OpenGL 변환 행렬로 구현되며 언제든지 원래대로 되돌릴 수 있습니다.

---

**Q5: Phase 5 기능을 WinCC Advanced에서도 사용할 수 있나요?**

A: 예, Phase 5 기능은 WinCC Advanced v17 호환성을 유지하며 구현되었습니다. UserControl을 WinCC에 삽입 후 동일하게 사용할 수 있습니다.

---

### 선택 기능 질문

**Q6: 선택된 컨투어/엘리먼트를 프로그래밍 방식으로 접근할 수 있나요?**

A: 예, `SelectionManager` 클래스의 공개 속성을 통해 접근 가능합니다:
- `SelectedContour`: 선택된 컨투어의 (partIndex, contourIndex)
- `SelectedElements`: 선택된 엘리먼트의 HashSet<(partIndex, contourIndex, elementIndex)>

이를 활용하여 추가 기능을 구현할 수 있습니다.

---

**Q7: 선택 허용 오차를 변경할 수 있나요?**

A: 현재 UI에서는 불가능하지만 코드에서는 가능합니다:
```csharp
selectionManager.ClickTolerance = 20.0; // 기본값: 10.0 픽셀
```
향후 버전에서 UI 옵션으로 추가될 예정입니다.

---

**Q8: 선택 시 자동으로 확대할 수 있나요?**

A: 현재 버전에서는 수동으로 줌 인/아웃해야 합니다. 자동 프레임 맞춤 기능은 향후 버전에서 추가될 예정입니다.

---

### 파트 외곽선 질문

**Q9: 커스텀 점선 패턴을 추가할 수 있나요?**

A: 현재 6가지 미리 정의된 패턴만 사용 가능합니다. 커스텀 패턴 정의는 향후 기능으로 고려 중입니다. 

현재 지원되는 패턴:
- Solid, Dash1, Dash2, Dash3, DotDash, DotDotDash

---

**Q10: 파트 외곽선의 여백(Margin)을 조정할 수 있나요?**

A: 현재는 Bounding Box를 기준으로 정확히 그려집니다. 여백 조정 기능은 향후 추가될 예정입니다.

---

### 번호 위치 설정 질문

**Q11: 번호 위치를 일괄적으로 리셋할 수 있나요?**

A: 다음 방법으로 가능합니다:
1. 빈 JSON 파일 불러오기:
   ```json
   {
     "customPartPositions": {},
     "customContourPositions": {}
   }
   ```
2. 또는 프로그램을 재시작하고 위치 파일을 불러오지 않기

개별 번호 리셋 기능은 향후 추가될 예정입니다.

---

**Q12: 번호 크기나 폰트를 변경할 수 있나요?**

A: 현재는 RenderSettings의 전역 설정을 따릅니다. 개별 번호의 스타일 변경은 향후 기능으로 계획 중입니다.

---

**Q13: 번호가 화면 밖으로 이동하면 어떻게 되나요?**

A: 번호는 설정된 World 좌표에 표시되므로 화면 밖으로 이동할 수 있습니다. 패닝 또는 줌 아웃하면 다시 볼 수 있습니다.

---

### 캔버스 회전 질문

**Q14: 임의의 각도로 회전할 수 있나요?**

A: 현재는 90도 단위(0°, 90°, 180°, 270°)만 지원합니다. 임의 각도 회전은 향후 기능으로 고려 중입니다.

---

**Q15: 회전 시 애니메이션이 있나요?**

A: 아니요, 회전은 즉시 적용됩니다. 부드러운 회전 애니메이션은 향후 추가될 수 있습니다.

---

**Q16: 3D 회전(X, Y축)을 지원하나요?**

A: 아니요, 현재는 2D 평면 회전(Z축)만 지원합니다. 3D 뷰는 CAM Viewer의 범위를 벗어납니다.

---

### 성능 및 호환성 질문

**Q17: 복잡한 MPF 파일에서 성능 문제가 있나요?**

A: Phase 5 기능은 성능에 미치는 영향이 최소화되도록 설계되었습니다:
- 선택: O(n) 복잡도, 일반적으로 < 1ms
- 경계 계산: 캐싱으로 반복 계산 방지
- 번호 위치: Dictionary 조회로 O(1) 성능

수천 개의 세그먼트가 있는 파일에서도 60 FPS 렌더링을 유지합니다.

---

**Q18: Phase 4 기능과 호환되나요?**

A: 예, Phase 5는 Phase 4의 모든 기능과 완전히 호환됩니다:
- MPF 파싱 및 렌더링
- 시뮬레이션 (Contour/Element)
- 렌더 설정
- 배경 이미지

Phase 5는 기존 기능을 확장하며 충돌하지 않습니다.

---

**Q19: .NET Core / .NET 5+ 에서 작동하나요?**

A: 현재는 .NET Framework 4.7.2 타겟입니다. .NET Core/5+ 마이그레이션은 향후 계획에 포함될 수 있습니다.

---

### 데이터 질문

**Q20: 선택 정보를 내보낼 수 있나요?**

A: 현재는 UI에서 직접 내보내기 기능이 없지만, JSON과 유사한 형식으로 저장하는 기능을 추가할 수 있습니다. 향후 버전에서 고려 중입니다.

---

**Q21: 여러 MPF 파일에 대한 번호 위치를 관리할 수 있나요?**

A: 각 MPF 파일에 대해 별도의 JSON 파일을 저장하는 것을 권장합니다:
- `ColdAir.mpf` → `ColdAir_positions.json`
- `test_mpf.mpf` → `test_mpf_positions.json`

프로젝트 폴더에서 파일명 규칙을 일관되게 유지하세요.
