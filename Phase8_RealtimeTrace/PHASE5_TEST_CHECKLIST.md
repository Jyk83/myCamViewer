## 🎯 Phase 5.1 & 5.2: 선택 기능 테스트

### 기능 5.2.1: 컨투어 선택 (Contour Selection)

#### 기본 기능

- [ ] **선택 모드 활성화**
  - "컨투어 (Contour)" 라디오 버튼 선택
  - 로그에 "Selection mode changed to: Contour" 출력

- [ ] **컨투어 클릭 선택**
  - 캔버스에서 컨투어 경로 클릭
  - 선택된 컨투어가 **노란색(Yellow)**으로 변경
  - 선택된 컨투어의 선 두께가 **2.5배** 증가
  - 로그에 선택된 컨투어 인덱스 출력

- [ ] **다른 컨투어 선택 (선택 전환)**
  - 다른 컨투어 클릭
  - 이전 선택이 해제되고 원래 색상으로 복원
  - 새로 선택된 컨투어가 노란색으로 하이라이트

- [ ] **빈 공간 클릭 (선택 해제)**
  - 컨투어가 없는 영역 클릭
  - 선택이 유지됨 (컨투어 모드는 명시적 해제 필요)

- [ ] **선택 모드 해제**
  - "없음 (None)" 라디오 버튼 선택
  - 선택이 해제되고 모든 컨투어가 원래 색상으로 복원
  - 로그에 "Selection mode changed to: None" 출력

#### 엣지 케이스

- [ ] **작은 컨투어 선택**
  - 매우 작은 컨투어 (직경 < 5mm) 클릭
  - 정상적으로 선택됨

- [ ] **복잡한 컨투어 선택**
  - 많은 세그먼트(50개 이상)를 가진 컨투어 클릭
  - 성능 저하 없이 선택됨

- [ ] **줌 인 상태에서 선택**
  - 줌 레벨 5x 이상 확대
  - 컨투어 선택 정상 작동

- [ ] **줌 아웃 상태에서 선택**
  - 줌 레벨 0.2x 이하 축소
  - 컨투어 선택 정상 작동

### 기능 5.2.2: 엘리먼트 선택 (Element Selection)

#### 단일 선택

- [ ] **선택 모드 활성화**
  - "엘리먼트 (Element)" 라디오 버튼 선택
  - 로그에 "Selection mode changed to: Element" 출력

- [ ] **직선 세그먼트 선택**
  - 직선 세그먼트 클릭 (중심 근처)
  - 선택된 세그먼트가 **마젠타(Magenta)**로 변경
  - 선택된 세그먼트의 선 두께가 **1.5배** 증가
  - 로그에 선택된 엘리먼트 인덱스 출력

- [ ] **호(Arc) 세그먼트 선택**
  - 호 세그먼트 클릭
  - 정상적으로 선택되고 마젠타로 하이라이트

- [ ] **다른 엘리먼트 선택 (선택 전환)**
  - 다중 선택 비활성화 상태에서 다른 세그먼트 클릭
  - 이전 선택이 해제되고 새 세그먼트만 선택됨

#### 다중 선택

- [ ] **다중 선택 활성화**
  - "다중 선택 (Multi-select)" 체크박스 체크
  - 로그에 "Multi-select enabled" 출력

- [ ] **Ctrl + 클릭으로 추가 선택**
  - 첫 번째 세그먼트 클릭 (선택됨)
  - **Ctrl 키를 누른 상태로** 두 번째 세그먼트 클릭
  - 두 세그먼트 모두 마젠타로 선택됨
  - Ctrl + 클릭으로 세 번째, 네 번째 세그먼트 추가 선택

- [ ] **Ctrl + 클릭으로 선택 해제**
  - 이미 선택된 세그먼트를 Ctrl + 클릭
  - 해당 세그먼트만 선택 해제되고 원래 색상으로 복원
  - 다른 선택은 유지됨

- [ ] **다중 선택 비활성화**
  - "다중 선택 (Multi-select)" 체크박스 해제
  - 여러 세그먼트가 선택된 상태에서 새 세그먼트 클릭
  - 이전 선택들이 모두 해제되고 새 세그먼트만 선택됨

#### 클릭 허용 오차 테스트

- [ ] **중심 클릭**
  - 세그먼트 중심을 정확히 클릭
  - 정상 선택됨

- [ ] **중심에서 5픽셀 떨어진 위치 클릭**
  - 세그먼트 근처(5픽셀 이내) 클릭
  - 정상 선택됨 (기본 허용 오차: 10픽셀)

- [ ] **중심에서 15픽셀 떨어진 위치 클릭**
  - 세그먼트에서 멀리(15픽셀 이상) 클릭
  - 선택 실패 (허용 오차 밖)

#### 엣지 케이스

- [ ] **첫 번째 세그먼트 선택**
  - 컨투어의 첫 번째 세그먼트(elementIndex = 0) 클릭
  - 정상 선택됨

- [ ] **마지막 세그먼트 선택**
  - 컨투어의 마지막 세그먼트 클릭
  - 정상 선택됨

- [ ] **짧은 세그먼트 선택 (< 1mm)**
  - 매우 짧은 세그먼트 클릭
  - 줌 인 후 정상 선택됨

- [ ] **여러 파트에 걸친 다중 선택**
  - 파트 A의 세그먼트 선택
  - Ctrl + 클릭으로 파트 B의 세그먼트 추가 선택
  - 두 파트의 세그먼트 모두 선택 유지

### 기능 5.2.3: 시뮬레이션 중 선택

#### 컨투어 시뮬레이션 + 선택

- [ ] **시뮬레이션 전 선택**
  - 컨투어 선택 모드에서 컨투어 선택 (노란색)
  - "Contour Sim" 버튼 클릭
  - 시뮬레이션 시작

- [ ] **시뮬레이션 중 하이라이트 유지**
  - 시뮬레이션이 선택된 컨투어에 도달하기 전: 노란색 유지
  - 시뮬레이션이 선택된 컨투어를 가공 중: 색상 변화 (시뮬레이션 색상 우선)
  - 시뮬레이션이 지나간 후: 노란색 하이라이트 복원 안 됨 (정상 동작)

- [ ] **시뮬레이션 중 선택 변경**
  - 시뮬레이션 실행 중
  - 다른 컨투어 클릭
  - 선택이 즉시 변경되고 새 컨투어가 노란색으로 하이라이트

- [ ] **시뮬레이션 일시정지 후 선택**
  - "Pause" 버튼 클릭
  - 컨투어 선택/선택 해제 정상 작동

- [ ] **시뮬레이션 리셋 후 선택**
  - "Reset" 버튼 클릭
  - 선택된 컨투어가 노란색으로 다시 표시됨

#### 엘리먼트 시뮬레이션 + 선택

- [ ] **시뮬레이션 전 다중 선택**
  - 엘리먼트 선택 모드에서 여러 세그먼트 선택 (마젠타)
  - "Element Sim" 버튼 클릭
  - 시뮬레이션 시작

- [ ] **시뮬레이션 중 선택된 엘리먼트 추적**
  - 선택된 세그먼트들이 가공될 때 색상 변화 관찰
  - 시뮬레이션이 지나간 후 마젠타 하이라이트는 복원 안 됨 (정상 동작)

- [ ] **시뮬레이션 중 선택 추가**
  - 시뮬레이션 실행 중
  - Ctrl + 클릭으로 새 세그먼트 추가 선택
  - 즉시 마젠타로 하이라이트됨

## 🔲 Phase 5.3: 파트 외곽선 테스트

### 기능 5.3.1: 외곽선 표시

#### 기본 표시

- [ ] **외곽선 활성화**
  - "Render Settings" 버튼 클릭
  - "파트 외곽선 표시 (Show Part Boundaries)" 체크박스 체크
  - "OK" 클릭
  - 모든 파트 주위에 사각형 외곽선이 표시됨

- [ ] **외곽선 비활성화**
  - "Render Settings" → 체크박스 해제 → "OK"
  - 외곽선이 사라짐

- [ ] **파트 번호와 함께 표시**
  - "파트 외곽선 표시" 체크박스 해제 상태
  - "파트 번호 표시" 활성화
  - 외곽선이 자동으로 표시됨 (파트 번호 표시 시 외곽선도 표시)

#### 외곽선 스타일 설정

- [ ] **색상 변경**
  - "Render Settings" → 외곽선 색상 버튼 클릭
  - 빨간색 선택 → "OK"
  - 외곽선이 빨간색으로 변경

- [ ] **선 두께 변경**
  - 두께 스피너를 1.5 → 3.0으로 변경
  - 외곽선이 두꺼워짐

- [ ] **점선 패턴 테스트 - Solid**
  - 패턴 드롭다운 → "Solid (실선)" 선택
  - 외곽선이 연속된 실선으로 표시

- [ ] **점선 패턴 테스트 - Dash1**
  - 패턴 → "Dash1 (긴 점선)" 선택
  - 외곽선이 `---- ---- ----` 패턴으로 표시

- [ ] **점선 패턴 테스트 - Dash2**
  - 패턴 → "Dash2 (중간 점선)" 선택
  - 외곽선이 `--- --- ---` 패턴으로 표시

- [ ] **점선 패턴 테스트 - Dash3**
  - 패턴 → "Dash3 (짧은 점선)" 선택
  - 외곽선이 `-- -- --` 패턴으로 표시

- [ ] **점선 패턴 테스트 - DotDash**
  - 패턴 → "DotDash (점-선)" 선택
  - 외곽선이 `-.-.-.-` 패턴으로 표시

- [ ] **점선 패턴 테스트 - DotDotDash**
  - 패턴 → "DotDotDash (점-점-선)" 선택
  - 외곽선이 `..-..-..-` 패턴으로 표시

#### 줌/패닝 테스트

- [ ] **줌 인 시 외곽선**
  - 5x 이상 줌 인
  - 외곽선이 파트와 함께 확대됨
  - 점선 패턴이 명확히 보임

- [ ] **줌 아웃 시 외곽선**
  - 0.2x 이하 줌 아웃
  - 외곽선이 파트와 함께 축소됨
  - 점선 패턴이 촘촘하게 보이거나 실선처럼 보일 수 있음 (정상)

- [ ] **패닝 시 외곽선**
  - 왼쪽 버튼 드래그로 화면 이동
  - 외곽선이 파트와 함께 이동함

#### 경계 계산 정확도

- [ ] **단순 파트 경계**
  - 사각형 파트의 외곽선 확인
  - 모든 컨투어를 포함하는 최소 사각형으로 그려짐

- [ ] **복잡한 파트 경계**
  - 여러 컨투어를 가진 파트의 외곽선 확인
  - 모든 컨투어를 포함하는 Bounding Box 정확히 계산됨

- [ ] **호를 포함한 경계**
  - 호(Arc) 세그먼트를 포함한 파트의 외곽선
  - 호가 16개 세그먼트로 근사되어 정확한 경계 계산됨

## 📍 Phase 5.4: 번호 위치 설정 테스트

### 기능 5.4.1: 파트 번호 위치 설정

#### 기본 기능

- [ ] **위치 설정 모드 활성화**
  - "파트 번호 위치 (Part #)" 버튼 클릭
  - 마우스 커서가 **십자선(Crosshair)**으로 변경
  - 로그에 "Number positioning mode enabled: Part" 출력

- [ ] **파트 선택 및 위치 지정**
  - 파트의 아무 위치나 클릭 (Bounding Box 내부)
  - 원하는 위치 클릭 (두 번째 클릭)
  - 파트 번호가 클릭한 위치로 즉시 이동
  - 마우스 커서가 기본 화살표로 복원
  - 로그에 "Part number position set: ..." 출력

- [ ] **다른 파트 번호 이동**
  - "파트 번호 위치 (Part #)" 버튼 다시 클릭
  - 다른 파트 클릭 → 위치 지정
  - 정상 작동

#### 취소 기능

- [ ] **Esc 키로 취소**
  - "파트 번호 위치 (Part #)" 버튼 클릭
  - **Esc 키** 입력
  - 위치 설정 모드 종료, 커서 복원
  - 로그에 "Number positioning mode disabled" 출력

- [ ] **오른쪽 마우스 버튼으로 취소**
  - "파트 번호 위치 (Part #)" 버튼 클릭
  - **오른쪽 마우스 버튼** 클릭
  - 위치 설정 모드 종료, 커서 복원

#### 엣지 케이스

- [ ] **파트 외부 클릭**
  - 위치 설정 모드 활성화
  - 파트 Bounding Box 외부 클릭 (첫 번째 클릭)
  - 파트가 선택되지 않음 (정상 동작)
  - 다시 시도 가능

- [ ] **번호를 화면 밖으로 이동**
  - 파트 선택 후 캔버스 끝 클릭
  - 번호가 화면 밖으로 이동함
  - 패닝/줌 아웃하면 다시 볼 수 있음

- [ ] **번호를 다른 파트와 겹치는 위치로 이동**
  - 파트 A의 번호를 파트 B의 위치로 이동
  - 정상 이동 (겹침 허용, 사용자 책임)

### 기능 5.4.2: 컨투어 번호 위치 설정

#### 기본 기능

- [ ] **위치 설정 모드 활성화**
  - "컨투어 번호 위치 (Contour #)" 버튼 클릭
  - 마우스 커서가 **십자선(Crosshair)**으로 변경
  - 로그에 "Number positioning mode enabled: Contour" 출력

- [ ] **컨투어 선택 및 위치 지정**
  - 컨투어 경로 클릭 (Point-in-Polygon 감지)
  - 원하는 위치 클릭 (두 번째 클릭)
  - 컨투어 번호가 클릭한 위치로 즉시 이동
  - 마우스 커서가 기본 화살표로 복원
  - 로그에 "Contour number position set: ..." 출력

- [ ] **다른 컨투어 번호 이동**
  - "컨투어 번호 위치 (Contour #)" 버튼 다시 클릭
  - 다른 컨투어 클릭 → 위치 지정
  - 정상 작동

#### 취소 기능

- [ ] **Esc 키로 취소**
  - 위치 설정 모드에서 Esc 키 입력
  - 모드 종료, 커서 복원

- [ ] **오른쪽 마우스 버튼으로 취소**
  - 위치 설정 모드에서 오른쪽 버튼 클릭
  - 모드 종료, 커서 복원

#### 엣지 케이스

- [ ] **컨투어 외부 클릭**
  - 위치 설정 모드 활성화
  - 컨투어 경로가 아닌 빈 공간 클릭 (첫 번째 클릭)
  - 컨투어가 선택되지 않음 (정상 동작)
  - 다시 시도 가능

- [ ] **작은 컨투어 번호 이동**
  - 매우 작은 컨투어 클릭
  - 줌 인 후 정확히 선택됨
  - 위치 지정 정상 작동

- [ ] **번호를 컨투어 외부로 이동**
  - 컨투어 선택 후 컨투어 외부의 빈 공간 클릭
  - 정상 이동 (외부 배치 허용)

### 기능 5.4.3: 위치 저장 및 불러오기

#### 저장 기능

- [ ] **위치 저장**
  - 파트 번호 및 컨투어 번호를 여러 개 이동
  - "위치 저장 (Save Positions)" 버튼 클릭
  - 파일 저장 대화상자에서 `test_positions.json` 입력
  - "저장" 클릭
  - 성공 메시지: "위치 정보가 저장되었습니다." 표시

- [ ] **JSON 파일 확인**
  - 텍스트 에디터로 `test_positions.json` 열기
  - 형식 확인:
    ```json
    {
      "customPartPositions": {
        "0": { "x": 0.5, "y": 0.3 }
      },
      "customContourPositions": {
        "0_0": { "x": 0.1, "y": 0.2 }
      }
    }
    ```

- [ ] **빈 위치 저장**
  - 아무 위치도 변경하지 않은 상태에서 저장
  - JSON 파일에 빈 객체 저장됨:
    ```json
    {
      "customPartPositions": {},
      "customContourPositions": {}
    }
    ```

#### 불러오기 기능

- [ ] **위치 불러오기**
  - 프로그램 재시작 또는 다른 MPF 파일 로드
  - "위치 불러오기 (Load Positions)" 버튼 클릭
  - 이전에 저장한 `test_positions.json` 선택
  - "열기" 클릭
  - 성공 메시지: "위치 정보를 불러왔습니다." 표시
  - 캔버스에 번호들이 저장된 위치로 표시됨

- [ ] **존재하지 않는 인덱스 처리**
  - JSON 파일에 존재하지 않는 파트/컨투어 인덱스 포함
  - 불러오기 시 해당 인덱스는 무시됨
  - 존재하는 인덱스는 정상 적용
  - 에러 없음

- [ ] **잘못된 JSON 형식 처리**
  - 형식이 잘못된 JSON 파일 불러오기 시도
  - 에러 메시지 또는 무시됨
  - 프로그램 크래시 없음

#### 줌/패닝 독립성

- [ ] **위치 설정 후 줌 인**
  - 번호 위치 설정
  - 5x 이상 줌 인
  - 번호가 상대 위치 유지 (파트와 함께 확대)

- [ ] **위치 설정 후 줌 아웃**
  - 0.2x 이하 줌 아웃
  - 번호가 상대 위치 유지 (파트와 함께 축소)

- [ ] **위치 설정 후 패닝**
  - 화면 이동
  - 번호가 파트와 함께 이동 (상대 위치 유지)

## 🔄 Phase 5.5: 캔버스 회전 테스트

### 기능 5.5.1: 기본 회전

#### 회전 각도 설정

- [ ] **0° (기본)**
  - "Render Settings" → "캔버스 방향" → "0° (기본)" → "OK"
  - 파트가 원래 방향으로 표시 (회전 없음)

- [ ] **90° CW (시계방향)**
  - "캔버스 방향" → "90° CW (시계방향)" → "OK"
  - 파트가 시계방향으로 90도 회전
  - 좌표축: X → Y, Y → -X

- [ ] **180°**
  - "캔버스 방향" → "180°" → "OK"
  - 파트가 180도 회전 (상하좌우 반전)
  - 좌표축: X → -X, Y → -Y

- [ ] **270° CW (반시계방향)**
  - "캔버스 방향" → "270° CW (반시계방향)" → "OK"
  - 파트가 시계방향으로 270도 회전 (반시계 90도와 동일)
  - 좌표축: X → -Y, Y → X

#### 회전 영향 확인

- [ ] **파트 및 컨투어 회전**
  - 90도 회전 설정
  - 모든 파트와 컨투어가 회전됨

- [ ] **파트 외곽선 회전**
  - 외곽선 표시 활성화
  - 90도 회전 설정
  - 외곽선도 함께 회전됨

- [ ] **피어싱 포인트 회전**
  - 피어싱 포인트 표시 (있는 경우)
  - 90도 회전 설정
  - 피어싱 포인트도 함께 회전됨

- [ ] **배경 이미지 회전** (설정된 경우)
  - 배경 이미지 로드
  - 90도 회전 설정
  - 배경 이미지도 함께 회전됨

- [ ] **번호 방향 유지**
  - 90도 회전 설정
  - 파트 번호 및 컨투어 번호는 **항상 읽기 쉬운 방향** 유지 (회전 안 됨)
  - **주의**: 현재 구현에서는 번호도 함께 회전될 수 있음 (구현 확인 필요)

#### 회전과 다른 기능의 상호작용

- [ ] **회전 + 줌 인/아웃**
  - 90도 회전 후 줌 인/아웃
  - 정상 작동, 회전 유지

- [ ] **회전 + 패닝**
  - 90도 회전 후 패닝
  - 정상 작동, 회전된 상태로 이동
  - 마우스 방향이 회전된 좌표계와 일치할 수 있음 (정상)

- [ ] **회전 + 선택**
  - 90도 회전 후 컨투어/엘리먼트 선택
  - 정상 작동, 선택 하이라이트 표시

- [ ] **회전 + 시뮬레이션**
  - 90도 회전 후 시뮬레이션 실행
  - 정상 작동, 회전된 상태로 시뮬레이션

- [ ] **회전 + 번호 위치 설정**
  - 90도 회전 후 번호 위치 설정
  - 정상 작동
  - 위치가 World 좌표로 저장되므로 회전 해제 시에도 상대 위치 유지

#### 연속 회전

- [ ] **0° → 90° → 180° → 270° → 0°**
  - 순서대로 회전 각도 변경
  - 각 단계에서 정상 회전 표시

- [ ] **180° → 0°**
  - 180도에서 바로 0도로 변경
  - 즉시 원래 방향으로 복원

- [ ] **설정 적용 없이 닫기**
  - "Render Settings" → 회전 각도 변경 → "Cancel" 클릭
  - 회전이 적용되지 않음 (이전 상태 유지)
